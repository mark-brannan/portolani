# Reefs and playas

Natural Earth's 10m reefs (lines, from coastlines) and 10m playas (salt flats and pans, a pinned download) drawn as their own ground layers, `scripts/reefs.mjs` and `scripts/playas.mjs`, each a style table like `scripts/water.mjs`. On by default in the page; off in the headless scene.

- `red-sea.png`: the Red Sea off Jeddah with reefs off, as crosses, and as red dots.
- `uyuni.png`: Salar de Uyuni with salt flats off, as pale salt, and as ruled clay.
- `page-redsea.png`, `page-reefs-off.png`: the page at the same view with both on (default) and off.

Lake Eyre is not in Natural Earth's playas (it is a lake there), so Salar de Uyuni stands in.
